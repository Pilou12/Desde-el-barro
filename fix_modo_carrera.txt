BUG #1 — La matriz registra el click con un frame de delay (doble click)
--------------------------------------------------------------------------------

ARCHIVO: src/ui/AppUI.js

CAUSA: En bindEvents(), los handlers usan `e.currentTarget` para leer
`data-cell-index` y `data-dir`. Con la asignación `btn.onclick = (e) => {}`,
`currentTarget` es null al momento de ejecución porque ya terminó la fase de
dispatching del evento. Hay que usar `btn` directamente (está capturado en el
closure) en vez de `e.currentTarget`.

Este bug afecta TRES bloques distintos. Reemplazá cada uno:

---------- REEMPLAZO 1 de 3 (matriz de copa) ----------

BUSCAR EXACTAMENTE:
    // Minijuego de Copa: Matriz
    const matrixBtns = document.querySelectorAll(".btn-matrix-cell");
    matrixBtns.forEach(btn => {
      btn.onclick = (e) => {
        const idx = Number(e.currentTarget.getAttribute("data-cell-index"));
        this.engine.resolveCupMatrixClick(idx);
        this.render();
      };
    });

REEMPLAZAR CON:
    // Minijuego de Copa: Matriz
    const matrixBtns = document.querySelectorAll(".btn-matrix-cell");
    matrixBtns.forEach(btn => {
      btn.onclick = () => {
        const idx = Number(btn.getAttribute("data-cell-index"));
        this.engine.resolveCupMatrixClick(idx);
        this.render();
      };
    });

BUG #2 — El botón "Siguiente" no funciona al terminar una copa
--------------------------------------------------------------------------------

ARCHIVO: src/domain/CareerEngine.js

CAUSA: El método `continueFromCup()` llama a `_transitionToNextCupOrEnd()`.
Si ya no quedan más copas en `player.qualifiedCups`, ese método cambia
`seasonPhase` a "SEASON_END" pero NO limpia `activeMinigame`. Como el objeto
sigue teniendo `status: "WON"` o `"ELIMINATED"`, cuando AppUI llama a
`render()` después, detecta `this.engine.activeMinigame` con valor y vuelve
a renderizar la pantalla CUP_MATCH en lugar de avanzar al resumen de temporada.

La solución es limpiar `activeMinigame = null` en `_transitionToNextCupOrEnd()`
cuando no quedan más copas.

BUSCAR EXACTAMENTE:
  _transitionToNextCupOrEnd() {
    // Buscar la próxima copa a jugar
    if (this.player.qualifiedCups && this.player.qualifiedCups.length > 0) {
      const nextCup = this.player.qualifiedCups.shift(); // Saca la primera de la lista
      if (nextCup === "copa_argentina") {
        this.seasonPhase = "CUP_NATIONAL";
      } else {
        this.seasonPhase = "CUP_INTERNATIONAL";
      }
      const playerStat = this.player.position.getPrimaryStatValue(this.player.attributes);
      this.activeMinigame = MinigameEngine.generateCupMatrix(nextCup, this.player.calculateOVR(), playerStat, this.currentTeam.power);
    } else {
      // Si no quedan copas, terminamos la temporada
      this.seasonPhase = "SEASON_END";
    }
  }

REEMPLAZAR CON:
  _transitionToNextCupOrEnd() {
    // Buscar la próxima copa a jugar
    if (this.player.qualifiedCups && this.player.qualifiedCups.length > 0) {
      const nextCup = this.player.qualifiedCups.shift(); // Saca la primera de la lista
      if (nextCup === "copa_argentina") {
        this.seasonPhase = "CUP_NATIONAL";
      } else {
        this.seasonPhase = "CUP_INTERNATIONAL";
      }
      const playerStat = this.player.position.getPrimaryStatValue(this.player.attributes);
      this.activeMinigame = MinigameEngine.generateCupMatrix(nextCup, this.player.calculateOVR(), playerStat, this.currentTeam.power);
    } else {
      // Si no quedan copas, terminamos la temporada.
      // Limpiar activeMinigame para que AppUI no vuelva a renderizar CUP_MATCH.
      this.activeMinigame = null;
      this.seasonPhase = "SEASON_END";
    }
  }

FIN DE LOS CAMBIOS
================================================================================

Resumen de lo que se cambió y por qué:

1. AppUI.js — 3 bloques de forEach con btn.onclick:
   Se eliminó el parámetro `e` del handler y se reemplazó
   `e.currentTarget.getAttribute(...)` por `btn.getAttribute(...)`.
   Razón: con `onclick =` (no addEventListener), `currentTarget` es null
   al ejecutarse el handler. `btn` está capturado correctamente en el closure.

2. CareerEngine.js — método _transitionToNextCupOrEnd():
   Se agregó `this.activeMinigame = null;` en el branch else (cuando no
   quedan más copas). Razón: sin limpiar el minijuego anterior, AppUI sigue
   viendo un activeMinigame activo y re-renderiza CUP_MATCH indefinidamente,
   impidiendo que el botón "Siguiente" avance al resumen de temporada.
